# ⭐ Featured Projects

### 🧠 [VeriDex](https://github.com/RakeshRautDev/VeriDex)

**Multimodal misinformation detection & digital forensics**

A research-oriented project exploring misinformation detection using NLP, multimodal analysis, evidence retrieval, and digital-forensics techniques.

`Python` `Transformers` `RoBERTa` `DeBERTa` `CLIP` `Gemini` `Streamlit`

---

### 🗳️ [NetaKhoj](https://github.com/RakeshRautDev/NetaKhoj)

**Electoral & civic intelligence platform**

A full-stack platform for exploring constituency and representative information using APIs, scraping, geospatial data, real-time communication, and backend services.

`Node.js` `Express` `MongoDB` `WebSockets` `Docker` `GIS`

---

### 📄 [JSK PDF Suite](https://github.com/RakeshRautDev/JSK-PDF-Suite)

**Desktop PDF productivity suite**

A practical desktop application built around document-processing workflows including PDF manipulation, compression, conversion, redaction, signatures, watermarks, and batch operations.

`Python` `PyMuPDF` `PyInstaller` `Desktop`

---

### 🌐 [NetTracer](https://github.com/RakeshRautDev/NetTracer)

**Network intelligence & diagnostics**

Investigates DNS, TLS, HTTP headers, IP/ASN information, routing, and network paths with real-time streaming.

`Python` `FastAPI` `WebSockets` `Networking` `Security`

---

### 📱 [MorphKeys](https://github.com/RakeshRautDev/MorphKeys)

**Turn an Android phone into a Bluetooth HID keyboard**

An Android application using Bluetooth HID capabilities to make a phone function as a wireless keyboard.

`Kotlin` `Android` `Bluetooth HID`

---

### 🗺️ [CivicSpatial API](https://github.com/RakeshRautDev/CivicSpatial-API)

**Geospatial civic-information API**

Converts geographic coordinates into useful civic and jurisdictional information through spatial processing and external APIs.

`Node.js` `Express` `Turf.js` `REST API`

---

### 🛰️ [Orbital Command](https://github.com/RakeshRautDev/Orbital-Command)

**Interactive orbital visualization**

A visualization project exploring satellite/orbital objects, propagation, tracking, and space-related datasets.

`JavaScript` `Orbital Mechanics` `Visualization`
